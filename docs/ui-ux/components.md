## Component rules

- `PhotoGrid`: `FlatList numColumns={3}`, tile size = `(screenWidth - 2*gap)/3`, gap 2, no outer padding (edge-to-edge) on My Photos; padded 20 on admin All photos if the design uses rounded tiles.
- `PhotoTile` badge slots: `topLeft` (status), `topRight` (reported), `bottomRight` (stack count). Never put two badges in one slot.
- `CountdownChip` tone: `warn` when remaining < 72 h; `closed` when passed.
- `Dialog` primary action color: `primary` for non-destructive (Log out), `danger` for destructive.
- `Sheet` footers sit inside the sheet, with content bottom padding ≥ footer height.
- Every list component supports skeleton, empty, and error props.
